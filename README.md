# free-statistical-tools
A curated collection of useful online statistical calculators and research resources.
## Useful Statistical Calculators

This repository shares useful online resources for students, researchers, and people learning statistical analysis.

### Nonparametric Statistical Tests

**Kruskal–Wallis H Test Calculator**

The Kruskal–Wallis test is used to compare three or more independent groups. It is commonly used when analysing ordinal data or when the assumptions of a one-way ANOVA are not suitable.

Use the [Kruskal–Wallis H Test Calculator](https://freestatisticaltools.com/kruskal-wallis-test-calculator/) to explore this statistical method.

### Who Can Benefit?

- Students studying statistics and research methods
- Researchers analysing data
- Analysts learning nonparametric tests

Always check the assumptions of a statistical test before interpreting its results.
